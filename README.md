# 地球 Online · 人生 explore

> 人生是一场地图未开的游戏。这个仓库是我的**探索日志**——
> 目前正在跑的那场探索：养成「另一个我」，一个可被测量的第二判断主体。

内核（规则与原理）在另一个仓库：[color-U/another-me](https://github.com/color-U/another-me)。
这个仓库只放数据：押注、结算、立场、经历、里程碑。

## 攻略 vs 探索

2026 年 9 月《高性价比人生指南》（howtolivebetter）上线，一个月 2.7 万星：734 页、690 条建议，每条标注成本、收益、证据。它是**攻略**——前提是地图已知，你负责挑。

这个仓库是**探索**——前提是地图未开，**日志即内容**：

| | 攻略 | 探索 |
|---|---|---|
| 内容是谁写的 | 作者 | 我自己（每次押注是一格） |
| 信任来源 | 证据分级 A/B/C | 规则保证不可篡改（R3：写定不改） |
| 数量观 | 690 条，越多越好 | 3 条就 3 条，空的就空着 |
| 终点 | 标记「已做到」 | 每周结算，押注见输赢 |

攻略整本讲「选什么」，没人讲「选完之后怎么对待」。我跑的这场探索补这一层——七条第一性原理见[内核仓的底层文档](https://github.com/color-U/another-me/blob/main/docs/first-principles.md)。

## 探索对象：另一个我

一个共享我的记忆与价值观、长着我性格缺陷、但拥有独立信息与独立推理的第二自我。

放进「地球 Online」的框架：**它是我派往迷雾地图的探员。** 每一次押注（「今天哪个判断，我愿意押一周后回看？」）是地图上点亮的一格；每一次结算，记录这块地是实地还是沼泽。地图不预设，走过去才亮。

## 日志的真实性由什么保证

- **R3 禁止事后修改**：归档的判断永远不许改，只能追加「现在怎么看待当初」
- **R10 谁在写的声明**：每条记录标注「我写的」还是「它生成的」
- **结算只追加**：结算时只填「结果」列，文末追加结算记录
- **空的就空着**：`log/disagreements.md` 现在是 0 条——那就是 0 条
